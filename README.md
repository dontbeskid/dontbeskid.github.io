## English

### What is this?

**cloudrepo** is a small personal repo with hand-picked tweaks for jailbroken iOS devices. It has its own App Store-style website in dark and light mode, a live catalog, and one-tap adding to your package manager.

- Works with **Sileo**, **Zebra**, **Cydia** and **Installer**
- **Rootless** friendly (`iphoneos-arm64`)
- Native Sileo tweak pages with icons
- Site in **English** and **Russian**

### How to add the repo

**The easy way:** open **[dontbeskid.github.io](https://dontbeskid.github.io/)** on your iPhone and tap **Open in Sileo** (Zebra, Cydia and Installer buttons are there too).

**Manually:** copy this URL

```
https://dontbeskid.github.io/
```

and add it to your package manager:

| App | Where |
|---|---|
| **Sileo** | Sources → **+** → paste the URL |
| **Zebra** | Sources → **+** → paste the URL |
| **Cydia** | Sources → Edit → Add → paste the URL |
| **Installer** | Repos → **+** → paste the URL |

Then pull down on the Sources tab to refresh, open **cloudrepo** and install whatever you like.

> Some tweaks need other packages (for example Orion). If an install fails on a missing dependency, add the repo that provides it.

### Как добавить репо

**Быстро:** открой **[dontbeskid.github.io](https://dontbeskid.github.io/)** на iPhone и нажми **Open in Sileo** (кнопки для Zebra, Cydia и Installer там же).

**Вручную:** скопируй ссылку

```
https://dontbeskid.github.io/
```

и добавь её в менеджер пакетов:

| Приложение | Куда |
|---|---|
| **Sileo** | Sources → **+** → вставь ссылку |
| **Zebra** | Sources → **+** → вставь ссылку |
| **Cydia** | Sources → Edit → Add → вставь ссылку |
| **Installer** | Repos → **+** → вставь ссылку |

После этого потяни вниз на вкладке Sources, чтобы обновить список, открой **cloudrepo** и ставь любые твики.

> Некоторым твикам нужны другие пакеты (например, Orion). Если установка падает из-за зависимости, добавь репо, где этот пакет лежит.
